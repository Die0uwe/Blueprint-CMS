# Hallo wereld — voorbeeldplugin

Kopieer deze map als startpunt voor je eigen plugin. Zie `docs/plugins.md` voor alle regels.
Activeren: `/admin/plugins` → Activeren (of `php cli/console.php plugin:activate example-hello-world`).
Daarna: zet `[hallo]` in een pagina, of gebruik de knop "👋 Hallo" in de editor.
